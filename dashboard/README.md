# Dashboard (工具控制台看板)

> [!NOTE]
> 本目录当前为架构预留占位状态，暂未正式实现前端应用代码。

## 规划介绍

未来这里将构建一个基于 **Vue 3 + Vite + TailwindCSS / Modern UI** 的轻量级可视化 Dashboard。

## 核心用途

1. **展示工具列表**：按分类（`gaming`, `finance`, `study`, `productivity`, `life`）自动聚合并呈现仓库内的所有工具卡片。
2. **查看工具状态**：实时显示各个工具的环境依赖就绪情况、配置项完整度以及最新运行状态。
3. **快速跳转 README**：集成 Markdown 渲染能力，支持在线查看各个独立工具的说明文档与使用指南。
4. **支持工具启动**：未来将对接轻量后端或本地执行通道，支持在 Web 端一键触发工具任务或设置定时调度。

## 当前状态

目前仅保留结构占位。新增工具时无需修改此目录。
