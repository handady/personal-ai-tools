# 灰度守护 · 操作与维护手册

> 一个让 Windows 屏幕「到点变灰、到点恢复」的小工具。
> 目的：用灰度滤镜掐断深夜打游戏的心流，逼自己按时睡觉。

---

## 一、它解决的问题

熬夜打游戏最难的不是「知道该睡了」，而是**心流上来了停不下来**。

屏幕上颜色一没，游戏画面立刻变成一堆灰白噪点，那种"再来一局"的冲动会断掉一大半。
手动按 `Win + Ctrl + C` 是能做到，但**手动的东西一定会被自己说服着不去做**。

所以这个工具把这件事变成了系统的事：

| 时间 | 屏幕 |
| --- | --- |
| 每天 23:00 | 变成灰度 |
| 每天 07:30 | 恢复彩色 |

你不用记得、不用点、也不用做任何决定。

---

## 二、它是怎么工作的

这个工具**没有发明任何新东西**，它只是替你去按那个 `Win + Ctrl + C` 快捷键。

Windows 自带的「颜色滤镜」功能（设置 → 辅助功能 → 颜色滤镜）可以把屏幕变成灰度，
并且提供了一个全局快捷键 `Win + Ctrl + C` 来开关它。开关状态存在这里：

```
HKEY_CURRENT_USER\SOFTWARE\Microsoft\ColorFiltering
    Active        = 0 或 1     ← 滤镜开没开
    FilterType    = 0          ← 0 就是「灰度」
    HotkeyEnabled = 1          ← 快捷键是否可用
```

工具的完整逻辑就三步：

1. **算**：看看现在几点，判断"现在应该是什么颜色"。
2. **看**：读一下 `Active`，知道现在实际是什么颜色。
3. **动**：如果不一致，就模拟按一次 `Win + Ctrl + C`（和手动按完全同一条路径），再读一遍确认改成功了。
   开灰度前还会做一次**前置自检**：确认「滤镜类型＝灰度」「快捷键可用」，如果被人改过就顺手校正回来并记进日志。

所以它不是"魔改"系统，**只是把你本来会手动做的事自动化了**。

### 设置面板上那三个开关，别搞混（重要）

打开「设置 → 辅助功能 → 颜色滤镜」，你会看到三个开关/选项。它们各管各的：

| 面板上的东西 | 对应注册表 | 你需不需要手动管 |
| --- | --- | --- |
| 顶部「**颜色滤镜**」大开关 | `Active` | **不用管**。它显示「关」是完全正常的 —— 程序会自己替你去按快捷键把它开/关 |
| 中间滤镜单选框（灰度 / 红绿色 / 蓝黄色…） | `FilterType` | **不用管，但别去点别的**。程序每次开灰度前会自己校正回「灰度」 |
| 底部「**颜色筛选器的键盘快捷方式**」开关 | `HotkeyEnabled` | **必须保持「开」**。这是快捷键的总闸，关掉它程序就完全失效（安装脚本会自动保证它是开的） |

> **一句话记法**：大开关是"现在有没有滤镜"，快捷键开关是"按键能不能用"。
> 程序靠"按键"工作，所以**它需要的是快捷键开关＝开**，而不是大开关＝开。
> 大开关初始为「关」，正说明此刻还没按过快捷键 —— 白天就该这样。

> **那这个快捷键开关要用户手动开吗？——不需要。**
> 它就是注册表里的 `HotkeyEnabled` 一个值，程序可以直接写：
> - **安装时**：如果它是 `0`（或整个键都不存在），`安装.cmd` 会自动补成 `1`，并在结果里提示"已重新启用 Win+Ctrl+C 快捷键"。
> - **运行期间**：每次开灰度前还会再复查一次，万一被改回去也会自动纠正并记进日志。
>
> 实测印证：把 `HotkeyEnabled` 写成 `0` 后模拟按键**完全无效**；写成 `1` 后**立即恢复**。
> 也就是说，新电脑上不需要你事先去设置里点任何东西，双击 `安装.cmd` 就行。

### 三个触发时机（关键设计）

真正让它"聪明"的是**什么时候**去对表：

| 触发 | 作用 |
| --- | --- |
| 每天 23:00 / 07:30 | 到点精确切换 |
| **每次开机登录** | 昨晚关机了，今早开机要补上 |
| **每次解锁屏幕** | 你中午才起床、一解锁电脑，它立刻发现"该彩色了"并恢复 |
| 每 10 分钟复查一次 | 兜底，也顺便把"手动偷偷按回彩色"纠正回来 |

> **关于"我 7:30 起不来"**：这条设计就是为它准备的。
> 07:30 那个时间点只是"最早可以变彩色的时刻"，而不是"必须在那一秒变彩色"。
> 你几点真的坐到电脑前解锁，它几点就恢复彩色。
> 电脑整晚关机 / 睡眠也不影响 —— 开机登录那一刻会重新对表。

## 三、安装

### 步骤

1. 把整个 `grayscale-guard` 文件夹放到你想放的位置（位置随意，桌面、D 盘、U 盘都行）。
2. 双击 **`安装.cmd`**。
3. 弹出「用户账户控制」窗口 → 点 **【是】**。
4. 看到「安装完成」即可。

> **为什么要点【是】？**
> Windows 规定：创建计划任务必须提权。这一步授权**只用于创建那一个计划任务**，
> 不会动系统文件。程序平时运行**不需要**管理员权限。

### 安装后建议做一次确认

双击 **`立即测试.cmd`** —— 屏幕会变灰 4 秒再恢复。
看到灰了，说明整条链路是通的。

### 安装脚本做了什么（全部清单）

1. 检查并补全 `HKCU\SOFTWARE\Microsoft\ColorFiltering` 的三个值（`Active` / `FilterType` / `HotkeyEnabled`），
   并把 `FilterType` 强制为 `0`（灰度）、`HotkeyEnabled` 强制为 `1`（快捷键可用）—— 如果原本不是，会在结果里提示你
2. 记录一份安装前的注册表快照（卸载时用来还原），存到 `logs\registry-snapshot.json`
3. 按 `config.json` 里的时间，注册一个名为 `GrayscaleGuard` 的计划任务
4. 立刻按当前时间对一次表

## 四、日常使用

安装完之后，**你不需要做任何事**。

到 23:00 屏幕变灰 → 你没法好好打游戏了 → 关机睡觉。
到第二天你开机 / 解锁，屏幕自动恢复彩色。

## 五、修改时间

### 方式一：双击 `修改时间.cmd`（推荐）

它会用记事本打开 `config.json`。改完保存、关掉记事本，**会自动重新应用**（会再弹一次提权窗口）。

### 方式二：直接编辑 `config.json`

```json
{
  "nightStart": "23:00",
  "morningEnd": "07:30",
  "recheckMinutes": 10,
  "enabled": true
}
```

| 字段 | 含义 |
| --- | --- |
| `nightStart` | 从这个时间开始变灰，24 小时制 `HH:MM` |
| `morningEnd` | 到这个时间恢复彩色，24 小时制 `HH:MM` |
| `recheckMinutes` | 每隔多少分钟自动复查一次。`10` = 每 10 分钟；`0` = 只在边界时刻 / 开机 / 解锁时检查 |
| `enabled` | 总开关。`false` = 完全不动手（但不会帮你把屏幕变回彩色） |

**常用改法：**

| 我想…… | 怎么改 |
| --- | --- |
| 提前一小时变灰 | `nightStart` 改成 `"22:00"` |
| 睡到 8 点 | `morningEnd` 改成 `"08:00"` |
| 更严格（手动按掉后 5 分钟就回来） | `recheckMinutes` 改成 `5` |
| 更宽松（只在两个时间点动手） | `recheckMinutes` 改成 `0` |
| 临时整体关掉 | `enabled` 改成 `false`，或直接双击 `暂停.cmd` |

> **改完为什么要"重新应用"？**
> 两个时间点会被写进计划任务的触发器里。只改 JSON 的话，新的时间段最迟在 `recheckMinutes` 分钟内生效；
> 想让 23:00 → 22:00 这种改变精确到分钟，重新跑一次 `安装.cmd`（或 `修改时间.cmd`）最稳妥。

## 六、临时停用 / 恢复

| 场景 | 做法 |
| --- | --- |
| 今晚要通宵赶工，不能变灰 | 双击 **`暂停.cmd`** → 屏幕立刻恢复彩色，守护停止动手 |
| 事情做完了，恢复正常 | 双击 **`恢复.cmd`** → 立刻对一次表，之后照常 |

`暂停.cmd` 做的事情其实就两件：在文件夹里放一个空的 `.paused` 文件，然后把屏幕恢复彩色。
`恢复.cmd` 就是把这个文件删掉。

> 也就是说：**你随时可以手动删掉 `grayscale-guard\.paused` 这个文件来恢复**，
> 不需要装任何东西、也不需要管理员权限。

## 七、检查状态

双击 **`检查状态.cmd`**，会打印一份这样的体检报告：

```
【1】配置          ← 现在的时间窗口、总开关、复查间隔
【2】此刻状态      ← 现在该灰还是该彩？实际是灰还是彩？一致吗？
【3】计划任务      ← 任务在不在、上次什么时候跑的、下次什么时候跑
【4】注册表原始值  ← Windows 自己存的那三个值
【5】最近日志      ← 最近的运行记录
```

**这是打消"它到底有没有在工作"疑虑最直接的工具。** 想知道它昨晚干了什么，看这里。

## 八、完全卸载

### 步骤

1. 双击 **`卸载.cmd`**
2. 弹窗点 **【是】**
3. 看它打印的校验结果（它会自己确认任务删掉了、屏幕是彩色的）

### 卸载脚本会做四件事

| # | 动作 |
| --- | --- |
| 1 | 删除计划任务 `GrayscaleGuard` |
| 2 | 关闭灰度滤镜，屏幕恢复彩色 |
| 3 | 把安装前记录的注册表原始值还原回去 |
| 4 | 删掉 `.paused` 停用标记 |

### 卸载完之后

**整个 `grayscale-guard` 文件夹可以直接删除**，系统里不会有任何残留。

## 九、为什么可以放心（重要）

如果你（或你身边的人）对"这东西关了以后到底干净没有"有疙瘩，请看这一节。这里给的每一条都是**你自己能亲眼验证的**。

### 9.1 它一共只碰了这些东西

| 类型 | 位置 | 说明 |
| --- | --- | --- |
| 计划任务 | 任务计划程序库 → `GrayscaleGuard` | **只有 1 个** |
| 注册表 | `HKCU\SOFTWARE\Microsoft\ColorFiltering` | 3 个值：`Active` / `FilterType` / `HotkeyEnabled` |
| 注册表 | `HKCU\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Accessibility` | 1 个值：`Configuration` |
| 文件夹 | `grayscale-guard\logs\`、`grayscale-guard\.paused` | 日志和停用标记，删文件夹即消失 |

以上全部都是 **`HKCU`（当前用户）级别**，不是机器级（`HKLM`）。

### 9.2 它明确【没有】做的事

- ❌ 没有安装任何**服务、驱动、内核组件**
- ❌ 没有添加任何**开机自启**（注册表 `Run` 项、启动文件夹都没动）
- ❌ 没有**常驻后台进程** —— 只在触发时刻启动一次 PowerShell，跑完立刻退出
- ❌ 没有**联网**，一行网络代码都没有
- ❌ 没有修改 `C:\Windows` 下的任何文件
- ❌ 没有修改 `HKLM`（机器级注册表）
- ❌ 运行时不使用管理员权限（计划任务以你本人身份、最低权限运行）

### 9.3 你自己怎么核实

**核实①：看计划任务**
```
Win + R → 输入 taskschd.msc → 回车 → 在左侧点「任务计划程序库」
→ 右侧列表里找 GrayscaleGuard
```
你会看到它只有一个，双击能看到它的完整配置：触发时机、运行什么命令。

**核实②：看注册表**
```
Win + R → 输入 regedit → 回车
→ 地址栏粘贴：HKCU\SOFTWARE\Microsoft\ColorFiltering
```
对比一下检查状态报告里列的值，就知道它有没有乱改。

**核实③：看日志**
打开 `grayscale-guard\logs\guard.log`，里面每一行都带时间戳。
你能完整地看到它什么时候动过手、动成了什么。

**核实④：卸载后复查**
`卸载.cmd` 最后会自己跑一遍校验并打印结果（✓/✗）。你还可以自己再打开 `taskschd.msc` 搜一次 `GrayscaleGuard` —— 搜不到就是真没了。

> 说到底：**它就是一个计划任务 + 四个注册表值。删掉这两样，它就等于从没来过。**

## 十、迁移到另一台电脑

1. 把**整个 `grayscale-guard` 文件夹**拷过去（U 盘、网盘、微信传都行，落哪儿都无所谓）。
2. 在新电脑上双击 **`安装.cmd`**，点【是】。

就可以了。安装脚本按**新电脑上的实际路径**重新注册任务，不会残留旧机器的信息。

> **注意**：如果安装之后你又移动了文件夹位置，计划任务里的路径就失效了 ——
> 重新双击一次 `安装.cmd` 即可。

## 十一、常见问题

**Q1：会不会拖慢电脑？**
不会。它**不常驻**。只在触发时刻（默认每 10 分钟一次、加上到点、开机、解锁）启动一个 PowerShell 进程，
读两个注册表值、判断一下、就退出。单次大约 1 秒、几十 MB 内存，跑完完全释放。
它不占 CPU、不占显存、不写持续日志。

**Q2：我手贱按了 `Win + Ctrl + C` 把灰度关掉，会怎么样？**
会被纠正回来 —— 最迟 `recheckMinutes` 分钟（默认 10 分钟）内自动恢复灰度。**这是故意设计的**，就是为了堵心流。

**Q3：我今晚真的要通宵加班，怎么办？**
双击 `暂停.cmd`。屏幕立刻恢复正常，守护不再动手。忙完双击 `恢复.cmd`。

**Q4：卸载之后会不会留下垃圾？**
不会。详见第九节。`卸载.cmd` 跑完会自己打印校验结果。

**Q5：为什么安装要管理员权限，运行时又不要？**
只有"创建计划任务"这一步需要 —— 任务调度器是系统级组件，Windows 强制要求提权。
任务本身以你本人身份、最低权限运行，所以日常执行不需要管理员。

**Q6：装完了，屏幕没变灰？**
先分清是"**没到时间**"还是"**真的坏了**"：
打开 `检查状态.cmd`，看【2】此刻状态。
- 显示"处于日间窗口内"→ 正常，等 23:00 就好。
- 显示"处于夜间窗口内"但实际没变灰 → 真的有问题，看第十二节。

**Q7：我中午才起床，早上那次恢复会不会漏掉？**
不会。你解锁屏幕的那一刻它就会对表。就算电脑整晚关着，开机登录时也会补上。

**Q8：能不能只在工作日生效？**
目前版本只支持一个连续时间段。如果你需要"周末不管"，这个改动很小，说一声可以加。

**Q9：设置里那个「颜色滤镜」大开关，要不要我先手动打开？**
**不用，而且它本来就该是「关」的。** 那个开关只表示"此刻有没有滤镜"，程序会在 23:00 自己替你去按快捷键把它打开、07:30 再关掉。
真正需要保持「开」的是面板**底部**那个「颜色筛选器的键盘快捷方式」（`HotkeyEnabled`）——它是快捷键的总闸。详见第二节的表格。

**Q10：我手动按了 `Win+Ctrl+C` 却什么也没发生？**
先看 `检查状态.cmd` 的【4】：
- `HotkeyEnabled` 是 `0` → 快捷键被关了，重新跑一次 `安装.cmd` 即可。
- `FilterType` 不是 `0` → 当前选中的滤镜不是灰度，重新跑一次 `安装.cmd`。
- 都正常但还是没反应 → 多半是被别的软件抢了 `Win+Ctrl+C`，或当前有独占全屏程序在前台（切到桌面再试）。
  即便快捷键一直失灵，**程序也有注册表兜底**，夜里照样能变灰。

## 十二、故障排查

### 症状：`立即测试.cmd` 跑了，屏幕不变灰

按顺序检查：

| 检查项 | 怎么做 |
| --- | --- |
| 1. 快捷键是否被禁用 | `检查状态.cmd` 看【4】，`HotkeyEnabled` 必须是 `1`。是 `0` 就重新跑一次 `安装.cmd` |
| 2. 滤镜类型是否被改 | 看【4】的 `FilterType`，`0` 才是灰度。不是 `0` 就重新跑 `安装.cmd` |
| 3. 有没有别的软件抢了这个快捷键 | 检查输入法、录屏、显卡工具（如 NVIDIA/AMD 面板）有没有占用 `Win+Ctrl+C` |
| 4. 是不是前台有独占全屏程序 | 某些全屏游戏会屏蔽模拟按键，切到桌面再试 |

### 症状：到点了没切换

| 检查项 | 怎么做 |
| --- | --- |
| 1. 是不是被暂停了 | 看文件夹里有没有 `.paused` 文件，有就双击 `恢复.cmd` |
| 2. 总开关 | 看 `config.json` 里 `enabled` 是不是 `false` |
| 3. 计划任务还在不在 | `检查状态.cmd` 看【3】 |
| 4. 时间格式 | `config.json` 里必须是 `"23:00"` 这种 24 小时 `HH:MM`，不能用 `23点` 或 `23:00:00` |
| 5. 看日志 | `logs\guard.log` 里会写清楚每次运行时判断的目标状态 |

### 症状：改了 config.json 但没生效

- 只改 JSON 的话，最迟 `recheckMinutes` 分钟内生效；想立刻生效，双击 `安装.cmd` 或 `修改时间.cmd`。

### 症状：卸载后屏幕还是灰的

按一次 `Win + Ctrl + C` 即可。（如果你在卸载前正好处于灰度状态，卸载脚本会帮你关，但万一被别的程序抢了，手动按一次最直接。）

### 找不到问题？看日志

```
grayscale-guard\logs\guard.log
```

每一行都是：`时间  发生了什么`。例如：

```
2026-10-10 23:00:12  [夜间] 目标=灰度（已开启） | 已切换 -> 灰度（已开启） | 方式=hotkey
2026-10-11 07:31:05  [日间] 目标=彩色（已关闭） | 已切换 -> 彩色（已关闭） | 方式=hotkey
```

`方式=hotkey` 表示走的是模拟快捷键（正常情况）；
如果出现 `方式=registry`，说明快捷键没生效、走了注册表兜底，这时可能需要重新登录一次才看得见效果。

## 十四、技术附录

### 注册表键值说明

| 路径 | 值名 | 类型 | 含义 |
| --- | --- | --- | --- |
| `HKCU\SOFTWARE\Microsoft\ColorFiltering` | `Active` | DWORD | `1` = 颜色滤镜开启；`0` = 关闭 |
| 同上 | `FilterType` | DWORD | `0` 灰度 / `1` 反转 / `2` 灰度反转 / `3` 绿色盲 / `4` 红色盲 / `5` 蓝色盲 |
| 同上 | `HotkeyEnabled` | DWORD | `1` = `Win+Ctrl+C` 可用 |
| `HKCU\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Accessibility` | `Configuration` | 字符串 | 滤镜启用时 Windows 会写成 `colorfiltering`，关闭时清空（由系统自己维护，工具不干预，仅在快捷键失效时兜底写入） |

### 计划任务配置要点

| 项 | 值 | 为什么 |
| --- | --- | --- |
| 名称 | `GrayscaleGuard` | 便于识别和手动删除 |
| 身份 | 当前用户 / `InteractiveToken` / 最低权限 | 必须运行在交互式会话里，模拟按键才能到达桌面；同时不需要管理员 |
| 触发器 | 每日 23:00（带 10 分钟重复）、每日 07:30、登录时、解锁时 | 见第二节 |
| `StartWhenAvailable` | 是 | 错过了时间点（比如当时在睡眠）补跑 |
| `WakeToRun` | 否 | **不主动唤醒电脑**，不会半夜把你机器叫起来 |
| `DisallowStartIfOnBatteries` | 否 | 笔记本电池状态下也正常执行 |
| `MultipleInstancesPolicy` | `IgnoreNew` | 不重复启动 |
| 日志保留 | 最近约 300 行 | 自动截断，不会无限增长 |

### 核心切换方式

模拟 `Win + Ctrl + C`（`keybd_event` 注入 `0x5B / 0x11 / 0x43`），与手动按快捷键走**完全相同**的系统路径。
切换后立刻回读注册表验证；若连续 3 次未生效，才退回到直接写注册表兜底，并在日志中标注。
