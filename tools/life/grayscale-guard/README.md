# 灰度守护 (Grayscale Guard)

给你的屏幕装一个作息表：**到点自动变灰，到点自动恢复彩色**。用来掐断深夜沉迷打游戏与刷视频的心流冲动，逼自己按时入睡。

---

## 功能

- **作息自动化**：默认每天 23:00 屏幕自动切换为黑白灰度，次日 07:30 自动恢复彩色。
- **系统原生极简**：依赖 Windows 辅助功能自带的「颜色滤镜」（即 `Win + Ctrl + C` 快捷键），不侵入系统内核，不注入任何驱动，不修改系统保护文件。
- **零常驻、零心智负担**：基于 Windows 原生任务计划程序定时唤醒对表，平时 0 内存占用、0 CPU 消耗、零后台进程常驻。
- **容错与自动对表**：支持开机登录、屏幕解锁以及每 10 分钟自动对表；即使熬夜到 2 点开电脑，也会立即感应为灰度。
- **双模体验**：既提供标准 Python CLI 命令行与交互式控制台，又保留原有快捷 `.cmd` 双击操作。
- **一键暂停与自检**：加班处理突发紧急工作时可一键临时暂停恢复彩色；自带 4 秒灰度快测工具。

---

## 输入

- **配置参数输入**：通过同目录下的 `config.json` 声明作息时段与检查频率。首次运行如不存在将自动进入交互式引导。
- **CLI 参数**：
  - `--status`：查看完整运行与系统健康度诊断，生成结构化状态产物。
  - `--install`：以管理员权限注册/更新 Windows 任务计划程序。
  - `--uninstall`：彻底移除任务计划并还原系统注册表。
  - `--test`：触发 4 秒灰度自检，肉眼确认视觉效果。
  - `--pause`：临时挂起守护（屏幕恢复彩色，停止定时干预）。
  - `--resume`：解除挂起并立即按当前作息对齐。
  - `--reconcile`：立即按当前时间对齐一次颜色。
- **外部依赖**：仅需 Windows 10 / 11 操作系统自带的颜色滤镜功能。

---

## 输出

- **`output/guard-status.json`**：结构化状态产物，包含当前作息时间段、当前屏幕色彩状态、任务计划注册状态、上次与下次触发时间，供 Toolkit Web 看板实时感应与渲染。
- **`output/status.md`**：Markdown 格式的健康状态简报。
- **`logs/guard.log`**：执行流水日志，记录每次对齐时间、颜色变化与自检校正结果（滚动保留最新 300 条）。
- **`logs/last-apply.txt`**：记录最后一次安装或修改时间的应用报告。
- **`logs/registry-snapshot.json`**：初次安装时保存的注册表原始快照，卸载时用于精准无痕还原。

## 环境配置

本工具严格遵循 `Personal AI Toolkit` 配置规范，通过本地 `config.json` 进行管理，**严禁且无需配置任何系统环境变量**。

配置文件参考 `config.example.json`：

```json
{
  "nightStart": "23:00",
  "morningEnd": "07:30",
  "recheckMinutes": 10,
  "enabled": true
}
```

- **`nightStart`**：夜间开始变灰时间（24小时制 HH:MM，如 23:00）。
- **`morningEnd`**：早晨恢复彩色时间（24小时制 HH:MM，如 07:30）。
- **`recheckMinutes`**：后台定时复查间隔（分钟），默认为 10 分钟。0 表示仅在边界时刻、开机与解锁时检查。
- **`enabled`**：守护总开关（布尔值）。

> **首次配置向导**：若 `config.json` 不存在，执行 `python main.py` 会自动在终端进入配置向导，询问作息后自动生成文件并提示重新运行。

## 安装依赖

本工具完全基于 Python 标准库与 Windows 原生 PowerShell 实现，**无需安装任何额外的 pip 第三方库**。

确保你的运行环境具备：
- Windows 10 / Windows 11
- Python 3.8 或更高版本
- PowerShell 5.1 或更高版本（Windows 系统自带）

```bash
pip install -r requirements.txt
```

## 运行方式

### 方式一：Python 统一入口 (推荐)

在工具根目录执行：

```bash
# 1. 启动交互式控制台菜单（首次运行将引导配置向导）
python main.py

# 2. 一键体检并导出状态产物
python main.py --status

# 3. 安装或更新计划任务（会弹出 UAC 提权确认）
python main.py --install

# 4. 立即测试 4 秒灰度效果
python main.py --test

# 5. 加班时临时暂停 / 恢复
python main.py --pause
python main.py --resume

# 6. 卸载计划任务
python main.py --uninstall
```

### 方式二：双击快捷脚本 (.cmd)

若习惯 Windows 桌面双击体验，同目录下提供了快捷脚本：
- **`安装.cmd`**：安装或重新应用新配置。
- **`检查状态.cmd`**：在终端打印系统体检报告。
- **`立即测试.cmd`**：屏幕变灰 4 秒后恢复，验证功能。
- **`暂停.cmd` / `恢复.cmd`**：临时停用或重新恢复。
- **`修改时间.cmd`**：记事本打开 `config.json`，修改保存关掉后自动重新应用。
- **`卸载.cmd`**：彻底清理计划任务与注册表。
